# ☕ Meu Repositório de Estudos em Java

Bem-vindo ao meu repositório de estudos! Este espaço foi criado para documentar a minha evolução prática na linguagem Java, aplicando conceitos que vão desde a lógica de programação até estruturas de dados avançadas e boas práticas de desenvolvimento back-end.

*Cada linha de código escrita aqui representa o foco, a disciplina diária e o suor da transição de carreira.*

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Linguagem Principal:** Java (JDK 25)
* **IDE:** IntelliJ IDEA
* **Controle de Versão:** Git e GitHub

---

## 📚 O que já foi consolidado até aqui:
Acompanhando o curso de Java do **Professor Nélio Alves**, meu motor de estudos já cobriu e consolidou:

* **Estrutura Sequencial, Condicional e Repetição:** Entrada, processamento e saída de dados controlados por laços (`for`, `while`) e condicionais estruturadas.
* **Orientação a Objetos (POO):** Criação de classes, atributos privados, construtores, encapsulamento (`getters` e `setters`) e customização do método `toString()`.
* **Gerenciamento de Memória (Stack vs Heap):** Entendimento prático de como o Java aloca variáveis primitivas e gerencia referências a objetos no Heap.
* **Estruturas de Dados Dinâmicas (Vetores de Objetos):** Criação e varredura de arrays estruturados.
* **Blindagem de Entrada de Dados:** Domínio no gerenciamento do buffer do `Scanner`, aplicando *parsing* de Strings (`Integer.parseInt` e `Double.parseDouble`) para evitar falhas de leitura.

---

## 📂 Destaque do Bloco: O Desafio do Pensionato
O maior marco desse módulo foi o desenvolvimento do **Desafio do Pensionato** (`DesafioPensionato.java`), onde apliquei:
* Mapeamento dinâmico de posições (ajuste entre o índice `0 a 9` da máquina para o quarto `1 a 10` do usuário).
* Painel de verificação de estados em tempo real (filtrando e exibindo quartos vagos com checagem de referências `null`).
* Relatório final limpo puxando dados formatados direto da entidade.
